操作說明

鍵盤　選鍵盤模式後啟動，保持控制台在前景。W/S 前後，A/D 轉向，方向鍵調整頭部，空白鍵停車。切換到其他視窗會停止輸入。

V7RC APP　從 V7RC 官方網站取得 APP，填入上方 IP 與連接埠。控制模式選 SRT 四通道，影像來源選 UDP，四通道先回到 1500。

自訂大腦　選 V7RC APP／自訂程式模式，先送 SRT1500150015001500# 接管 UDP 6188。向 UDP 8800 傳送 EF 00 04 00 訂閱頭部影像，從同一個接收 socket 重組 FF/45 JPEG 分片。影像中斷時送中立。影像封包說明
