# 轉向死區與斜推起步實測

2026-11-08，MacBook Pro M4。修改前用 Mac `0.1.0-preview.4` 安裝版，修改後用整合工作區 `main@798591a` 加本次橋接變更。兩組使用相同 MuJoCo 3.10.0、ONNX Runtime 1.24.4、平地 `scene_backlash.xml` 和 VelStand 模型。上游為 microduck `main@98ce17e`、microduck_rl `develop@bae39f5`。兩組均開視窗與本機影像訂閱，以隔離 UDP 連接埠每秒送 20 次 SRT。每次先回中約 2.2 秒，再持續操作 4 秒。修改前的條件另見 [Mac 安裝版操控對照](2026-11-08-macos-installed-stick-ab.md)。

CH1 預設 PWM 範圍中，1400 至 1600 含端點一律輸出零轉向，1399、1601 仍有左右輸出。CH2–CH4 保留原本的死區。斜推起步先漸升前進輔助，再漸入轉向。起步輔助退回穩態指令，持續推住時不重複觸發。

| 幅度 | 操作 | 修改前，4 秒 | 修改後，4 秒 |
| --- | --- | ---: | ---: |
| 15% | 前進 | 1.7 cm | 22.3 cm |
| 15% | 左轉 | 左 2.4° | 漂移約 0.2°，轉向命令為零 |
| 15% | 右轉 | 右 0.2° | 漂移約 0.2°，轉向命令為零 |
| 15% | 左斜推 | 0.1 cm | 20.9 cm，轉向命令為零 |
| 15% | 右斜推 | 約 0 cm | 19.9 cm，轉向命令為零 |
| 25% | 前進 | 23.9 cm | 24.2 cm |
| 25% | 左轉 | 左 64.6° | 左 62.9° |
| 25% | 右轉 | 右 84.0° | 右 85.2° |
| 25% | 左斜推 | 0.5 cm，左 5.1° | 26.1 cm，左 34.4° |
| 25% | 右斜推 | 0.5 cm，右 4.3° | 27.3 cm，右 42.9° |

25% 單軸數值各取兩輪平均，斜推欄採最後一版複測。15% 純前進穩態由接近零提升至 4.9 cm/s。15% 斜推雖然沒有轉向指令，最後一版的實際偏航仍為 1.5–7.6°，第一輪左斜推曾漂移約 20°。25% 斜推的穩態前進為 6.3–6.8 cm/s。30 輪均未跌倒，結果只涵蓋本機模擬與 SRT 發送端。原始樣本在 `.runtime/feel-ab/`。[原比例控制來源](https://github.com/v7rc/microduck-v7rc/commit/f5bbafe)
