# preview.8 控制台啟動與自由練習驗收

2026-11-08（台北），Apple Silicon Mac。基準為 [preview.7](https://github.com/v7rc/microduck-v7rc/releases/tag/v0.1.0-preview.7)，整合 commit `2dbca0e`。候選控制台沿用其已安裝 MuJoCo、robotd、內建 VelStand ONNX 和 Schema 2 曲線。SRT 由本機發送，另使用本機相機訂閱；未用手機或實體機器人驗收。

舊研究工作階段的 `robotd` 和 `tofd` 已由系統接管，仍對固定的 TCP 7801 重連。用短暫的 localhost 監聽和 `lsof` 確認了兩個連線程序。相同隔離啟動僅更換內部 TCP 埠：27801 的兩輪 25% 單軸右轉分別轉 91.5°、83.7°；插在中間的 7801 試驗沒有持續右轉，總角度反向 1.2°。7801 案例的日誌也顯示鴨子在起身前倒下；27801 保持坐姿，由 sitstand 起身。已停止辨識出的舊工作階段。

候選控制台每次啟動分配獨立的 localhost TCP 埠，並在關閉時使用同一個埠清理。手機控制和影像 UDP 埠不變。

| 自由練習測項 | Mac 控制台實測 |
| --- | --- |
| 25% 單軸右轉，三輪各 4 秒 | 右轉 82.2°、84.1°、81.0°；排除前 1.5 秒，平均右轉速度 17.6、18.8、16.0°/s |
| 25% 左／右斜推，各兩輪 4 秒 | 左平均 29.6°、右平均 37.6°，相差 8.0°；每輪前進 0.253–0.264 m |
| CH1 死區 | 1400、1425、1500、1575、1600 指令皆為零；1399 左轉 +0.0088 rad/s、1601 右轉 −0.0066 rad/s |

本次門檻：單軸右轉每個穩態半秒區段持續朝右且大於 5°/s；斜推每輪朝指定方向轉超過 12°、前進超過 0.12 m，左右平均轉角相差不超過 12°。
