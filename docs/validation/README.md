## 後續驗證項目

| 階段 | 應驗證項目 | 通過依據 |
| --- | --- | --- |
| 通訊 | 發現、連線、寫入、重新連線 | APP 版本、接收端設定與實際封包紀錄 |
| 解析與映射 | 正常／錯誤封包、中立、端點、方向、二進位資料 | 可重現輸入及預期輸出 |
| 失聯處理 | 輸入逾時、斷線、重啟、控制權競爭 | 明確狀態轉換及實際控制輸出 |
| 模擬器 | 移動、動作切換、停止行為 | 固定版本、設定、操作步驟及結果 |
| 實機 | 經確認範圍內的操作與失聯測試 | 硬體、韌體、環境及逐項結果 |

數值門檻（例如延遲、逾時及速度上限）應在測試前依控制介面與機器人條件確定。

## 單次紀錄格式

```markdown
# YYYY-MM-DD 測試主題
日期／操作者：
目的與測試層級：離線／模擬／實機
倉庫、branch/tag、commit：
APP、OS、硬體、韌體與通訊設定：
前置條件與操作步驟：
輸入與預期結果／通過門檻：
實際結果與證據位置：
判定：通過／失敗／未驗證
已知限制與下一步：
```

紀錄及附件不可包含憑證或含帳密的連線資訊。
