# Microduck 九乘六格迷宮尺寸

2026-11-08 依使用者提供的地圖轉繪。站姿模型的參考尺寸取自 [microduck_rl 的 scene_backlash.xml](https://github.com/pollen-robotics/microduck_rl/blob/bae39f5900b318f7e87fc485c30a31213cfa14eb/src/mjlab_microduck/robot/microduck/scene_backlash.xml)（`develop`，固定 commit `bae39f5`）。在 MuJoCo 載入 `STAND` 姿勢後，以機體可見網格頂點量測左右全寬及最低點到最高點的高度。目前場景採固定 300 mm 格距和 400 mm 牆高。實作前可用實機站姿複測機體尺寸，確認轉彎所需空間。

| 項目 | 尺寸 |
| --- | ---: |
| 站姿 Microduck 寬 × 高 | 142.057 × 271.616 mm |
| 格距（牆中心線到中心線） | 300 mm |
| 有雙側牆的一格淨寬 | 297 mm |
| 牆厚 × 牆高 | 3 × 400 mm |
| 地圖格線跨度（橫向 9 格 × 縱向 6 格） | 2700 × 1800 mm |
| 牆體外緣占地 | 2703 × 1803 mm，約 4.87 m² |

牆以格線為中心，所以外緣在每側比格線多 1.5 mm。占地含牆厚，支架、底座與接縫加工另計。模擬器中的牆端各延伸半個牆厚以封住接合處，現場裁料需依接法扣除交疊。

格線由左至右編號 0–9，由上至下編號 0–6。START 是左下格，END 是右上格。圖上綠色框視為試算表選取框，左上角的上緣和左緣已補牆，其他開口依原圖。下表的範圍代表兩端格線編號，兩端之間為一段連續牆。

| 水平牆所在列線 | 橫向範圍 | 垂直牆所在欄線 | 縱向範圍 |
| ---: | --- | ---: | --- |
| 0 | 0–9 | 0 | 0–5 |
| 1 | 2–3、5–6、7–8 | 1 | 1–2、3–5 |
| 2 | 1–5、7–8 | 2 | 0–1、4–6 |
| 3 | 0–1、2–4、5–6、7–8 | 4 | 0–1、3–4 |
| 4 | 2–4、5–6、7–8 | 5 | 2–3、4–5 |
| 5 | 3–5、7–9 | 6 | 1–3、4–6 |
| 6 | 0–9 | 7 | 0–1、4–5 |
| | | 8 | 1–2、3–4 |
| | | 9 | 1–6 |

從工作區執行 `scripts/console`，在場景選單選「九乘六格迷宮」，再按「啟動」。鴨子會放在 START 格中央，朝地圖右側，場內地面為白色，START 和 END 保留橘色，地面色層與字樣均為無碰撞標記。
