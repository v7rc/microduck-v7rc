# V7RC 協定研究筆記

查閱日期：2026-11-06。來源：[官方繁體中文協定](https://github.com/v7rc/V7RC-Protocol/blob/main/protocol.zh-TW.md)。狀態：文件研究，尚未擷取 APP 實際封包。

## 文件可確認的規格

- 協定以三碼命令開頭，`#` 結尾；主要規格為 20 bytes，新版 APP 不再支援舊 16-byte 格式。
- `SRV` 表示四組 PWM 欄位，`SR2` 表示第二組通道；`SRT` 的 Tank 轉換由韌體端處理。
- `HEX`、`DEG` 含 16 個原始資料位元組，解析時須按二進位封包處理。
- `CMD` 自訂命令最多 16 字元，規格要求以空白補足。

## 實作前待確認

- 使用者實際 APP 版本、iOS／Android、控制介面、可輸出的命令。
- BLE 掃描條件、裝置名稱、service／characteristic UUID、寫入屬性、配對要求；這份 IO 命令文件不足以確定完整 GATT 相容性。
- 封包頻率、搖桿中立值、實際端點、按鍵語意、斷線後最後一筆輸入的處理。
- 上游部分範例字串的長度與文字規格疑似不一致；實作前逐 byte 驗證，不直接將範例當成解析器測試標準。
- 二進位命令的資料可能包含與結尾相同的 byte，解析須依已確認的命令長度判斷邊界。

協定中的 PWM 值是輸入表示方式；如何對應 Microduck 的移動意圖屬本專案設計，尚未形成正式控制規格。
